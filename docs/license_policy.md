# License Policy

The Foundry is licensed under `AGPL-3.0-or-later`.

This is a strong copyleft license for networked software. It allows learning,
self-hosting, modification, redistribution, paid support, and commercial use,
but it requires modified versions to stay open under the same license when they
are conveyed or offered to users over a network.

## Project Intent

The Foundry should remain a public learning workshop.

Allowed:

- Run The Foundry locally.
- Study and modify the code.
- Share modified copies under the AGPL.
- Offer hosting, support, training, or consulting as long as AGPL obligations
  are followed.

Not aligned with the license intent:

- Taking The Foundry, modifying it, and offering a closed-source subscription
  service without giving users the corresponding source code.
- Embedding The Foundry into a proprietary derivative product in a way that
  avoids the AGPL source-sharing requirements.
